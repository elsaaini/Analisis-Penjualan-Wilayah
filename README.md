# Analisis Penjualan Barang per Wilayah
# Deskripsi
Analisis data penjualan dilakukan dengan Python dan Pandas untuk mengidentifikasi wilayah dengan jumlah penjualan tertinggi serta distribusi produk berdasarkan kategori. Proyek ini mencakup eksplorasi data, pemeriksaan tipe data dan missing values, pengelompokan data (groupby), agregasi total dan rata-rata penjualan, serta visualisasi data menggunakan diagram batang dan diagram lingkaran (pie chart) untuk memperoleh gambaran pola penjualan.
# Step:
1. Upload file
2. Cek tipe data
3. Cek nilai kosong
4. Kelompokkan data
5. Membuat urutan kelompok terbesar - terkecil
6. Visualisasi data
# Tools
1. Excel
2. Python
3. Pandas
# Hasil
Secara keseluruhan, hasil analisis menunjukkan bahwa jumlah penjualan berbeda-beda berdasarkan wilayah maupun kategori produk. DKI Jakarta menjadi wilayah dengan jumlah penjualan tertinggi, sedangkan kategori kebutuhan rumah merupakan kategori produk yang paling banyak terjual. Informasi ini dapat digunakan sebagai bahan pertimbangan dalam menentukan strategi pemasaran, distribusi produk, serta pengelolaan persediaan berdasarkan wilayah dan kategori produk.
